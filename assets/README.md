# assets/

Drop your media here. Filenames must match what `index.html` references (or update the
paths there). See the asset table in the project root `README.md` for sizes.

```
assets/
├── hero-keyart.jpg          1920×1080  hero background
├── trailer-poster.jpg       1280×720   trailer thumbnail
├── og-image.jpg             1200×630   social share image
├── favicon.ico
├── icon.svg
├── gifs/
│   ├── clip-1.gif
│   ├── clip-2.gif
│   └── clip-3.gif
└── screenshots/
    ├── shot-1.jpg … shot-6.jpg
```

Until you add these, the page shows neutral placeholders automatically.
